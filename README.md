## عن المشروع

رفوف هو متجر كتب عربي بتصميم Premium وتجربة استخدام RTL، يضم الكتب الرقمية والورقية، البحث والتصفية، تفاصيل الكتب، السلة، المؤلفين، والمدونة.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## التحقق والبناء

```bash
pnpm check
pnpm build
```

## بنية المصدر

- `client/src/pages/` صفحات الموقع.
- `client/src/components/` مكونات الواجهة المشتركة.
- `client/src/App.tsx` المسارات الرئيسية.
- `client/src/index.css` الهوية البصرية والتصميم المتجاوب.
- `docs/pasted_content.txt` المواصفات الأصلية الكاملة.

> الدفع، الحسابات، المخزون، المكتبة الرقمية، والتوصيات المتصلة ببيانات فعلية تحتاج إلى استكمال تكاملات الخلفية.
