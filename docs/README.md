# رفوف | منصة الكتب الرقمية والورقية

نسخة أولية قابلة للتصفح من منصة متجر كتب عربية RTL، مبنية وفق المواصفات المرفقة.

## ما تم تنفيذه

- واجهة عربية RTL متجاوبة للكمبيوتر والهاتف.
- هوية بصرية Premium بألوان كحلية وبنفسجية ومشمشية.
- Hero section مع أغلفة كتب عائمة.
- تصنيفات تفاعلية وتصفية للكتب.
- بطاقات كتب مع معاينة، مفضلة، وأسعار وخصومات.
- سلة تسوق جانبية مع ملخص الطلب.
- نافذة معاينة الكتاب.
- مساعد كتب ذكي تفاعلي بتوصيات تجريبية.
- قسم الأكثر مبيعًا والعروض والمدونة والنشرة البريدية.
- دعم الحركات الدقيقة وحالات النجاح والتغذية الراجعة.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

## التحقق

```bash
pnpm check
pnpm build
```

> هذه النسخة تمثل الواجهة وتجربة الاستخدام الأولى. الدفع، الحسابات، المخزون، المكتبة الرقمية، ومحرك التوصيات المتصل ببيانات فعلية تحتاج إلى استكمال تكاملات الخلفية في مرحلة لاحقة.
